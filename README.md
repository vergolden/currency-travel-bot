# Кошелёк путешественника

Telegram-бот для учёта финансов в поездках: конвертация валют через API
[exchangerate.host](https://exchangerate.host/documentation), несколько «путешествий» на
пользователя, учёт расходов с автоматическим пересчётом баланса в двух валютах.

## Функционал

- `/start` — приветствие и главное inline-меню
- `/newtrip` (или «Создать новое путешествие») — страна отправления → страна назначения →
  бот получает курс через API → подтверждение или ручной ввод курса → начальная сумма →
  создаётся путешествие со стартовым балансом в обеих валютах
- Любое сообщение с числом при активном путешествии — расход в валюте страны пребывания,
  бот показывает конвертацию и просит подтвердить (✅/❌) перед списанием
- `/switch` («Мои путешествия») — список путешествий, переключение между ними
- `/balance` («Баланс») — остаток активного путешествия в обеих валютах
- `/history` («История расходов») — список трат по активному путешествию
- `/setrate` («Изменить курс») — ручное обновление курса активного путешествия

## Архитектура

Модуль API отдельно от логики бота:

```
config.py         — загрузка .env
current_api.py     — клиент exchangerate.host (/live, /convert)
exceptions.py       — исключения модуля API
countries.py        — сопоставление «страна → код валюты» + приём кода валюты напрямую
database.py         — SQLite: путешествия и расходы
bot.py              — диалог (pyTelegramBotAPI), состояние в памяти процесса
cli.py              — консольный тест current_api.py отдельно от бота
```

**Важный нюанс:** курс запрашивается через API только один раз — при создании путешествия
или вручную через «Изменить курс». Каждый расход конвертируется **умножением/делением на уже
полученный курс**, без нового обращения к API — бесплатный тариф exchangerate.host даёт всего
100 запросов в месяц, и дергать API на каждую трату это исчерпало бы очень быстро.

## Запуск

```bash
cd projects/homework/currency_travel_bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впишите CURRENCY_API_KEY (exchangerate.host) и TELEGRAM_BOT_TOKEN (BotFather)

python cli.py    # тест модуля current_api в консоли
python bot.py     # запуск бота
```

## Стек

Python 3.12, [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI), requests,
python-dotenv, SQLite (стандартная библиотека), [exchangerate.host](https://exchangerate.host/documentation).
